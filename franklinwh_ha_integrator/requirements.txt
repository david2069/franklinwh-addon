# Phase 3 — SmartDispatch LP optimizer (v0.5.0, 2026-08-06).
# Pure-Python LP modeller + bundled CBC solver. ~2 MB install.
# Only imported by src/services/smart_dispatch/lp_optimizer.py when a
# gateway has `use_lp_optimizer=1` in smart_dispatch_config; otherwise
# the greedy heuristic in synthesize_and_optimize continues to serve.
# Upper bound is deliberate, same reasoning as fastapi above. lp_optimizer.py
# calls pulp.PULP_CBC_CMD, which PuLP 3.x deprecates and documents for removal
# in 4.0. Unbounded, the next image rebuild after that release would import
# cleanly and then fail to solve — falling back to the greedy heuristic
# silently, since the optimizer treats any solver failure as a fallback rather
# than an error. That is exactly how this dependency went unnoticed once
# already: the running image predated the requirement entirely and logged
# "No module named 'pulp'" every 30s for weeks.
