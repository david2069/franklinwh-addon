LocalVolts (P2P)

Australia — 5-minute P2P wholesale market

SD/AB integration: LocalVolts provides import_c_kwh and export_c_kwh live. Forecast and renewables % are not available — AB rules using those fields will evaluate as SKIP (unknown), not false.

AEMO NEM Wholesale

Australia — 30-minute National Electricity Market dispatch

NEM Region:

SD/AB integration: AEMO provides import price, renewables %, and 48-slot forecast. Export price is not available — AB export rules will evaluate as SKIP (unknown).

FranklinWH TOU Schedule

Static rates from the gateway's TOU schedule — any country

SD/AB integration: Provides full import + export price, tariff label, and schedule-derived 24h forecast. No real-time market data — rates change only when the TOU schedule is edited. Works globally with any utility.

ComEd Hourly Pricing

Real-time hourly wholesale electricity prices for ComEd (Illinois, US)

US · Illinois

What it provides

  • Real-time hourly import price (¢/kWh)
  • Next-hour forecast from ComEd API
  • Export/feed-in price — not available (net metering)
  • Renewables % — not available

Setup

No API key required. ComEd publishes hourly prices publicly.

To activate, go to Services → Edit Utility Service and set the pricing provider to comed.

SD/AB integration: ComEd provides import_c_kwh live. Spike detection and demand window are not available — AB rules using those fields will evaluate as SKIP (unknown).
