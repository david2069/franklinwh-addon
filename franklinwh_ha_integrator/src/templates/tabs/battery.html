Cell Bleed Status — 16S1P (Bit 0 = Cell 1)

Cells bleeding: 

Each bit corresponds to one cell. A set bit means that cell is actively being bled (bypass resistor engaged) to bring it in line with the pack average. Zero means all cells are within balance tolerance.

Prototype decode — the bit-to-cell mapping for the FranklinWH aPower 16S1P pack has not been officially confirmed. This display is based on the standard LFP BMS single-byte convention (bit 0 = Cell 1) extended to uint16 for 16 cells, but the actual encoding may differ. Treat as indicative only — subject to revision.
