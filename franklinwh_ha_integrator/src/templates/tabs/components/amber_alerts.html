Security & TLS Requirements

If you have enabled **Lock Dashboard & REST APIs** (Security Enabled):

  • HTTPS / SSL: Update host URLs to use https://. If using self-signed certs, add verify_ssl: false to HA's rest_command and REST sensor configurations to avoid connection handshake blocks.
  • Token Authentication: Any REST Sensors pulling telemetry (e.g. /api/automation/signal) must supply a **Long-Lived API Token** (generated in the Security tab) using the Authorization: Bearer fhai_... header or the query parameter ?token=fhai_....
